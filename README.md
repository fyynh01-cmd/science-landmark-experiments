# 科学里程碑实验速查 / Science Landmark Experiments

把《改变历史的100个实验》蒸馏为一套可复用的**科学实验速查 / 方法库**技能包。

- **覆盖**：心理学 50 项（`assets/psychology.md`）+ 物理学 50 项（`assets/physics.md`）。
- **统一骨架**：每条均为「背景假设 → 方法设计 → 关键结果 → 意义影响」四段，支持按年份 / 学科 / 研究者 / 主题检索与结构化蒸馏改写。
- **示例**：`examples/` 提供心理与物理各一个完整条目样板（米尔格拉姆、迈克尔逊-莫雷）。
- **元数据与校验**：`meta.json`、`VALIDATION.md`。

## 结构

```
science-landmark-experiments/
├─ SKILL.md                     # 技能定义（何时使用/核心概念/工作流/规则/边界）
├─ assets/
│  ├─ psychology.md             # 心理学 50 项里程碑实验速查表
│  └─ physics.md                # 物理学 50 项里程碑实验速查表
├─ examples/
│  ├─ README.md
│  ├─ psychology-milgram.md     # 心理学完整条目示例
│  └─ physics-michelson.md      # 物理学完整条目示例
├─ meta.json                    # 技能元数据
└─ VALIDATION.md                # 发布前校验清单
```

## 使用

- 想快速了解某实验 → 在对应学科的速查表中按名称/年份定位条目。
- 想按学科/年代/主题横向检索 → 使用速查表中的索引维度。
- 想把某实验改写为科普/讲义/脚本 → 以四段骨架为纲，用自己的语言重组。
